# موقع عروض الفرع + لوحة تحكم + كود QR

موقع ثابت (بدون سيرفر وبدون قاعدة بيانات) يعرض:

- **العروض** كملفات PDF مع تاريخ بداية ونهاية، وحالة تلقائية: ساري / قادم / منتهي مع عدّاد أيام.
- **حسابات التواصل الاجتماعي** بأيقونات وألوان كل منصة.
- **معلومات الفرع**: العنوان، الهاتف، الواتساب، الخريطة، ومواعيد العمل مع مؤشر «مفتوح الآن».
- **لغتان** عربي (افتراضي، RTL) وإنجليزي بزر تبديل.
- **صفحة `qr.html`** لتوليد كود QR وطباعة ملصق جاهز للفرع.
- **لوحة تحكم `/admin`** لرفع العروض بدون أي كود.

كل شيء مجاني بالكامل: الاستضافة والدومين وشهادة SSL ولوحة التحكم.

---

## بنية المشروع

```
index.html                 الصفحة الرئيسية
qr.html                    مولّد كود QR + ملصق للطباعة
content/site.json          بيانات الفرع (الاسم، العنوان، المواعيد، التواصل)
content/offers.json        قائمة العروض
offers/                    ملفات الـ PDF وصور الأغلفة
admin/index.html           لوحة التحكم
admin/config.yml           إعدادات لوحة التحكم  ← يجب تعديل سطر repo
assets/css | js | img      التصميم والسكربتات والشعار
netlify.toml               إعدادات النشر
```

## 1) النشر (مرة واحدة، حوالي ١٥ دقيقة)

### أ. ارفع المشروع على GitHub

1. أنشئ حسابًا مجانيًا على <https://github.com> إن لم يكن لديك حساب.
2. اضغط **New repository** ← اسم مثل `market-site` ← **Create repository**.
3. من داخل مجلد المشروع نفّذ:

```bash
git init && git add . && git commit -m "الموقع الأول" && git branch -M main
```

ثم اربطه بالمستودع وارفعه (غيّر الاسم والمستخدم):

```bash
git remote add origin https://github.com/USERNAME/market-site.git && git push -u origin main
```

> بديل بدون أوامر: من صفحة المستودع اضغط **uploading an existing file** واسحب كل ملفات المجلد.

### ب. اربطه بـ Netlify

1. سجّل الدخول على <https://app.netlify.com> بحساب GitHub (الخطة المجانية تكفي تمامًا).
2. **Add new site → Import an existing project → GitHub** واختر المستودع.
3. اترك `Build command` فارغًا و `Publish directory` = `.` ثم **Deploy**.
4. من **Site configuration → Site details → Change site name** اختر اسمًا مثل `aleqtisadi-egaila`
   فيصبح رابط الموقع: `https://aleqtisadi-egaila.netlify.app` — **هذا هو الدومين المجاني، ويعمل بشهادة SSL تلقائيًا ومدى الحياة.**

بعد أي تعديل من لوحة التحكم يعيد Netlify نشر الموقع تلقائيًا خلال ثوانٍ.

## 2) تفعيل لوحة التحكم `/admin`

لوحة التحكم تسجّل الدخول بحساب GitHub. تحتاج ربطًا لمرة واحدة:

### أ. عدّل `admin/config.yml`

```yaml
backend:
  name: github
  repo: USERNAME/market-site   # اسم حسابك / اسم المستودع
  branch: main
```

### ب. أنشئ تطبيق OAuth على GitHub

<https://github.com/settings/developers> ← **OAuth Apps** ← **New OAuth App**

| الحقل | القيمة |
|---|---|
| Application name | `Market Admin` |
| Homepage URL | `https://aleqtisadi-egaila.netlify.app` |
| Authorization callback URL | `https://api.netlify.com/auth/done` |

احفظ، ثم انسخ **Client ID** و **Generate a new client secret**.

### ج. أضفهما في Netlify

**Site configuration → Access & security → OAuth → Authentication providers → Install provider → GitHub**، والصق الـ Client ID والـ Secret.

انتهى. افتح `https://aleqtisadi-egaila.netlify.app/admin` واضغط **Login with GitHub**.

> لوحة التحكم تعمل من الموبايل، ويمكنك دعوة موظف عبر إضافته Collaborator على المستودع من GitHub — عندها يدخل بحسابه هو ولا يحتاج أي صلاحية أخرى.

## 3) إضافة عرض جديد

من `/admin`:

1. **العروض ← قائمة العروض ← Add عرض**
2. اكتب العنوان بالعربي (والإنجليزي اختياري)، ووصفًا مختصرًا.
3. حدّد **تاريخ البداية** و **تاريخ النهاية** — الموقع يتكفّل بالباقي:
   - قبل تاريخ البداية → شارة **«قريبًا»** في تبويب «القادمة».
   - بين التاريخين → شارة **«ساري»** مع عدّاد «باقي كذا يوم».
   - بعد تاريخ النهاية → ينتقل تلقائيًا إلى تبويب **«المنتهية»** بدون أي تدخل منك.
4. ارفع **ملف العرض (PDF)** — الموقع يأخذ **أول صفحة منه تلقائيًا كصورة للعرض** على الكارت. لا داعي لرفع صورة غلاف إلا لو أردت غلافًا مختلفًا (أو إذا كان الـ PDF كتالوجًا ضخمًا أكبر من ١٢ ميجابايت، فحينها ارفع صورة غلاف يدويًا).
5. فعّل **تثبيت في الأعلى** للعرض الأهم.
6. اضغط **Publish** — الموقع يتحدث خلال أقل من دقيقة.

## 4) كود QR

افتح `https://aleqtisadi-egaila.netlify.app/qr.html`:

- ضع رابط الموقع، وعدّل جملة الملصق.
- **تحميل PNG** بجودة عالية للطباعة، أو **تحميل SVG** لمصمم المطبوعات، أو **طباعة الملصق** مباشرة.
- خيار وضع الشعار في منتصف الكود (مستوى تصحيح الخطأ `H` مفعّل افتراضيًا حتى يظل الكود قابلًا للمسح).

**نصيحة:** اطبع بحجم لا يقل عن ٤×٤ سم للاستيكر و ١٥×١٥ سم للبوستر، واترك هامشًا أبيض حول الكود، وجرّب المسح قبل الطباعة بالكمية.

---

## 5) تعديل بيانات الفرع

من `/admin` ← **إعدادات الموقع**: الاسم، الفرع، لون الهوية، الشعار، الهاتف، الواتساب، العنوان، مواعيد العمل، وحسابات التواصل.

للخريطة: خرائط جوجل ← **مشاركة ← تضمين خريطة ← نسخ HTML**، والصقه كما هو في حقل «رابط تضمين الخريطة» (الموقع يستخرج الرابط تلقائيًا).

---

## 6) دومين خاص (اختياري)

الدومين المجاني `.netlify.app` يكفي. ولو اشتريت دومينًا لاحقًا:
**Netlify → Domain management → Add a domain** ثم اتبع تعليمات الـ DNS — شهادة SSL تُصدر تلقائيًا ومجانًا.

---

## 7) تشغيل الموقع محليًا للتجربة

الموقع يقرأ ملفات JSON عبر `fetch`، لذلك لا يعمل بفتح `index.html` مباشرة من المجلد؛ يحتاج خادمًا محليًا بسيطًا. أسهل طريقة على ويندوز:

```bash
npx serve .
```

## الهوية البصرية

اللوجو مُستخرَج من ملف `الاقتصادي.pdf` كرسم **فيكتور SVG** (مش صورة) — يعني يطلع حاد على أي مقاس ومع أي شاشة، وحجمه صغير:

| الملف | الاستخدام |
|---|---|
| `assets/img/logo.svg` | اللوجو الكامل (الاسم + «قول و فعل») — الهيدر والفوتر |
| `assets/img/logo-mark.svg` | عربة التسوق وحدها — العلامة المائية في الهيدر |
| `assets/img/favicon.svg` | أيقونة التبويب والموبايل (عربة بيضاء على مربع أزرق) |
| `assets/img/og.svg` | صورة المعاينة عند مشاركة الرابط |

الألوان مأخوذة من اللوجو نفسه: **أزرق `#0E50FC`** و **برتقالي `#FA2F00`** فوق خلفية كريمي `#FBF5EA`،
والاتنين قابلين للتغيير من `/admin ← إعدادات الموقع`.

## ملاحظات

- تقدر تشارك الرابط بلغة محددة: `?lang=en` للإنجليزي و `?lang=ar` للعربي.
- ملف `offers/sample-offer.pdf` مجرد ملف تجريبي — احذفه بعد رفع أول عرض حقيقي.
- صورة المشاركة `assets/img/og.svg` بصيغة SVG؛ لأفضل ظهور عند مشاركة الرابط على واتساب وفيسبوك استبدلها بصورة `og.jpg` بمقاس 1200×630 وعدّل وسم `og:image` في `index.html`.
- خطوط Cairo تُحمَّل من Google Fonts، ومكتبة كود QR من unpkg — كلاهما مجاني ولا يحتاج حسابًا.
